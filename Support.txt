#Raspberry Pi 5
  #Camera support
    #Arducam IXM708 does not read correctly on the raspberry pi 5. To make it read correctly, one must edit the config file in the raspberry pi itself.
    #To get to the config file to do this, type this into the command prompt:
      #Sudo nano /boot/firmware/config.txt
      #Under the [all] subtitle, add the following:
        #dtoverlay = imx708
          #Use “dtoverlay = imx708,cam0” if the arducam is connected through the CAM0 port
      #After adding that to the config file, save the file by using the command “Ctrl+O” then press enter, this will save the file. To exit the txt editor, use the command “Ctrl+X”.
    #Once these steps are completed you can either reboot your raspberry pi if your camera is already connected, or turn the raspberry pi off, connect the camera to the correct CAM port, and turn it back on.
    #To ensure this worked, go the command prompt and use this command:
      #Rpicam-still -o test.jpg
    #This allows the camera to take a picture and save it as “test.jpg”, but if you do not want a picture you can use “rpicam-hello”
      #We use rpicam in this instance as it is what replaced libcamera in the latest updates of the raspberry pi 5, if your pi is an older version/model, you may need to use the libcamera function as well as tweak the RFID code.
#Physical RFID support
  #If the only thing connected to the Pi is the RFID reader and the Camera:
    #The RFID reader does not come with header pins attached to the board, therefore you will have to either attach those and use female to female wires, or solder the wires into place
    #The pins or holes that are going to be used on the RFID board are the ANT1, ANT2, +5-9V, 3.3vTX, and GND
      #Pins/Holes ANT1 and ANT2 are for the copper loop, they can be connected to either wire, as it still does the same thing in reverse
    #The pins on the Pi that are going to be used are pin 2 (5V), pin 6 (GND), and pin 10 (GPIO15,RXD).
    #The board and reader are connected as follows:
      #+5-9V is connected to pin 2
      #3.3vTX is connected to pin 10
      #GND is connected to pin 6
